Cloud Reader · 私人书房

一个可以部署在 Cloudflare Pages 上的个人网页电子阅读器。使用浏览器管理书库、阅读电子书、记录笔记，并在手机与电脑之间同步阅读进度。

无需自建服务器。使用预先打包的 Pages ZIP，在控制台上传文件、绑定 D1 和 R2、设置部署密钥即可运行。

> 当前推荐 Pages 直接上传版。本文按现有功能编写，云端分段阅读目前适用于 UTF-8 TXT，其他格式的支持范围见下文。

## 功能介绍

### 私有书库

- 管理员初始化、账号密码登录、恢复码与设备会话管理。
- 批量选择或拖拽导入，按文件哈希去重。
- 标题、作者和标签搜索，卡片与列表视图。
- 收藏、评分、阅读状态、归档、回收站及书籍信息编辑。
- 原始书籍保存在私有 R2 桶，通过登录后的后端接口访问。

### 阅读体验

- 支持 TXT、EPUB、PDF、Markdown、HTML、DOCX、CBZ，以及基础 FB2。
- 三种翻页模式：仿真翻页（立体过渡效果）、简约翻页、上下滚动。
- 上下滚动模式到达边缘后继续滚动，可切换到上一章或下一章；云端 TXT 按段衔接。
- 沉浸阅读：工具栏默认隐藏，电脑将鼠标移到屏幕上下边缘唤出，手机点击正文中央或上下边缘唤出。
- 目录、搜索、书签、摘录、高亮及笔记导出。
- 字号、字体、主题、行距、段落间距、正文宽度和翻页模式可调整。
- 手机与电脑按设备分别保存设置，互不覆盖；支持本设备单书设置和默认设置。
- 阅读进度滑块位于“阅读设置”中，需要时再打开。

| 操作 | 作用 |
|---|---|
| ← / → | 切换章节；云端 TXT 切换段落，PDF 切换页面 |
| ↑ / ↓ | 滚动模式上下滚动；翻页模式按屏翻页 |
| PageUp / PageDown、空格 | 上一屏或下一屏 |
| 鼠标滚轮 / 手机滑动 | 按当前阅读模式滚动或翻页 |
| Tab | 唤出工具栏并进行键盘导航 |

### 云端分段阅读

在线打开 UTF-8 TXT 时，只读取当前约 **16 KiB** 的正文，并预取下一段。翻到后面或跳转时，再读取需要的内容；浏览器最多保留 5 段正文，不必先下载完整的长篇小说。

云端模式的“段”不等于原书章节，也不等于固定屏幕页数。字号和屏幕尺寸会影响每屏显示内容。该模式仅搜索已加载正文；需要全书搜索或断网阅读时，选择“完整下载 / 离线阅读”。

### 进度与离线

- 停止滚动或切换段落后自动保存进度，联网时同步到云端。
- 再次打开会先拉取云端进度，恢复章节或段号及段内相对位置。
- 同一账号可跨设备续读；云端分段与完整阅读分别保存进度。
- 完整下载后的书籍可使用独立离线口令解锁，IndexedDB 缓存使用 AES-GCM 加密。
- 同一标签页刷新可保留解锁状态，临时凭据最长 12 小时有效；退出登录后清除。
- 离线编辑的阅读记录、书签和笔记通过队列在联网后同步。

## 部署到 Cloudflare Pages

### 1. 准备部署包

使用与当前源码对应的 **`Cloud-Reader-Pages直接部署.zip`**。如果仓库维护者提供了发布附件，可使用其中的 Pages 部署包；如果只有源码，请按后面的“从源码构建”生成。

**GitHub 的 Code → Download ZIP 是源码压缩包，不能直接当作 Pages 部署包上传。**

正确部署包解压后，根目录应包含：

```text
_worker.js
_routes.json
index.html
```

网页和后端已经打包在 `_worker.js` 中，不要只上传 `index.html`，也不要在这三个文件外再套一层目录。

### 2. 创建 Pages 项目并上传

1. 登录 Cloudflare，进入 **Workers & Pages**。
2. 选择创建应用，进入 **Pages → 直接上传 / Upload assets**。
3. 填写项目名称，上传 Pages ZIP，或拖入解压后的三个文件。
4. 点击部署。初次缺少绑定时，页面显示配置提示属于正常情况。

这里采用 Pages Advanced Mode，官方支持通过控制台直接上传 `_worker.js`。这种方式不需要本地命令行或 GitHub 自动构建。选择直接上传后，若以后改用 Git 集成，需要新建相应项目。参见 [Cloudflare 直接上传文档](https://developers.cloudflare.com/pages/get-started/direct-upload/)。

### 3. 创建存储并绑定

在 Cloudflare 创建一个 D1 数据库和一个私有 R2 桶，名称可以自定。进入刚创建的 Pages 项目，在 **Settings → Bindings** 中为 **Production / 生产环境** 添加：

| 绑定类型 | 变量名（区分大小写） | 选择的资源 |
|---|---|---|
| D1 database | `DB` | 你的 D1 数据库 |
| R2 bucket | `BOOKS` | 你的私有 R2 桶 |

不需要开启 R2 公共访问，不需要配置 R2 API 密钥或 CORS，也不需要手动执行 SQL。首次访问初始化接口时自动建表。

### 4. 设置部署密钥

在项目的 **Settings → Variables and Secrets** 中添加加密变量（Secret）：

| 名称 | 值 |
|---|---|
| `DEPLOY_KEY` | 自己设置的部署密钥 |

支持任意长度的非空数字密码，前导 `0` 保留，也兼容字符串密钥。建议使用较长且不重复使用的值。

**保存绑定和密钥后，重新创建一次生产部署，上传同一个 Pages ZIP，让配置生效。**

DEPLOY_KEY 用于首次初始化及派生密码验证数据，已有书库不要随意更换。它不是日常登录密码。

### 5. 初始化管理员

打开项目的 `https://项目名.pages.dev` 主地址，填写：

| 输入项 | 要求 |
|---|---|
| 用户名 | 3～32 个字符，支持中文、字母、数字、下划线和短横线；不能包含内部空格 |
| 保留用户名 | 不能使用 `admin`、`root`、`api`、`setup`、`login`，不区分大小写 |
| 登录密码 | 10～256 个字符 |
| 初始化密钥 | 与 Cloudflare 中的 `DEPLOY_KEY` 完全一致 |
| 离线解锁口令 | 至少 8 个字符，独立于登录密码 |

例如，用户名可使用 `reader01`。创建完成后妥善保存恢复码，再设置离线口令并导入书籍。

## 更新与迁移

更新时，在原 Pages 项目创建新的生产部署，上传新版 Pages ZIP。保留原 `DB`、`BOOKS` 和 `DEPLOY_KEY`，无需重新初始化管理员或重新导入书籍。

从控制台 Worker 版迁移到 Pages 时沿用原数据库、桶和部署密钥；若原部署额外设置过 `PASSWORD_PEPPER`，也必须保留相同的 Secret。从旧命令行版迁移时，保留原 `PASSWORD_PEPPER`。更换网站域名后需要重新登录，旧域名的离线缓存不会自动搬到新域名。

完整操作见 [Pages 部署教程](docs/Pages直接部署.md)。仍使用 Worker 的用户可参考 [Worker 控制台部署教程](docs/控制台直接部署.md)；早期命令行流程见 [部署与备份教程](docs/部署教程.md)。

## 从源码构建

开发环境建议使用 Node.js 24 与 npm。进入源码根目录运行：

```sh
npm ci
npm run build:pages
```

生成结果：

- `Cloud-Reader-Pages直接部署.zip`：上传到 Pages 的部署包。
- `pages-release/`：构建文件和可在浏览器打开的部署说明。

普通用户拿到预构建部署包后，无需执行上述命令。仅执行 `npm run build` 只会生成前端资源，部署 Pages 完整应用请使用 `npm run build:pages`。

### 本地开发与检查

```sh
npm run types
npm run typecheck
npm run lint
npm test
node scripts/dev-pages-test.mjs
```

最后一条命令基于已有 Pages 构建包，在独立临时目录创建本地 D1/R2 测试环境，默认端口为 `8795`。测试密码仅用于本机环境，不可用于生产。

端到端测试的环境变量及操作步骤见 [测试说明](docs/测试说明.md)。本地模拟测试不等于所有实机和生产环境均已验证。

## 常见问题

**提示“输入格式不正确”？** 先检查用户名是否用了保留名称（例如 admin），以及登录密码是否至少 10 位。

**绑定已经设置，页面仍提示缺少配置？** 检查变量名、生产环境选择，并在保存后重新部署。

**TXT 不能云端分段阅读？** 当前要求 UTF-8。GBK/GB18030 等编码可选择完整下载阅读，或先转换为 UTF-8 再导入。

**工具栏不见了？** 这是沉浸模式。电脑移动鼠标到上下边缘，手机点击正文中央即可显示。进度滑块在阅读设置中。

**换设备后进度没有及时更新？** 确保使用同一账号、相同阅读模式，并在原设备联网后返回书架。断网或强制关闭浏览器前尚未同步的操作，可能只保存在原设备。

**刷新后仍要输入离线口令？** 新版本首次需要解锁一次；临时会话过期、退出登录或浏览器禁用会话存储后需要重新输入。浏览器恢复关闭的标签页可能恢复临时会话，共用设备请主动退出登录。

## 当前限制与费用

- 云端分段目前仅支持 UTF-8 TXT；PDF、EPUB 等仍按原方式读取完整文件，大文件可能受到设备内存限制。
- EPUB 使用简化排版，DOCX 不保证还原 Word 布局；PDF 不含 OCR、完整文本批注层或全书搜索。
- 仿真翻页为立体过渡效果，不是物理纸张卷曲模拟。
- 云端与完整阅读的定位方式不同，进度与笔记按模式区分；不同屏幕恢复的具体行可能略有差异。
- 本项目面向个人书库，尚无多用户管理界面、OPDS、网盘接入、AI 或 OCR。
- 默认单书上限 200 MiB、站点预算 8 GiB，是应用配置，不是免费额度或账单保证。
- Pages 版请求由 Functions 处理；分段读取也会产生 R2 请求。R2 开通条件和实际费用以账户及官方计费规则为准。
- Pages 版不自带 Worker Cron 清理任务。长期使用需关注失败上传、数据库与同步日志的容量，并定期备份 D1 和 R2。
