# Cloud Reader · 私人云端阅读器

一个部署在 Cloudflare Pages 上的多用户电子书阅读器。每位用户拥有独立书库、阅读进度、书签、笔记和本地缓存，适合个人与家庭自建阅读空间。

**当前版本：v1.15.0**。重点优化大 EPUB 首屏：正文与图片分开加载、相邻图片按需获取、大压缩项后台解压。保留全文搜索、漫画模式、精确位置记忆和跨设备阅读接续。

## v1.15.0 首页与书库管理

- **继续阅读**：首页突出显示一本书的封面、书名、作者、当前章节或分段、进度及上次阅读时间；旁边可切换最近四本书，再点击继续阅读。直接使用已保存进度，不为首页预下载正文。没有封面的书使用文字封面。
- **简洁书籍卡片**：卡片保留封面、书名、作者和进度；“更多”集中提供编辑信息、离线下载、下载原文件、移动到未读/在读/已读/归档及移入回收站。回收站书籍可恢复。
- **封面网格与紧凑列表**：两种显示方式切换，按当前账号在此浏览器记住选择，刷新后恢复。
- **批量管理**：“选择”进入管理模式，支持全选当前筛选结果、追加标签、归档、加入离线下载和移入回收站。部分失败时，任务中心重试只处理失败项。批量删除为可恢复的回收站操作。
- **任务中心**：顶部统一查看每个文件的导入阶段、上传进度、离线下载进度和阅读数据同步状态；支持失败重试。云服务的未完成备份/恢复任务也可在此继续。导入和同步记录留在本页内存中，导入失败文件刷新后需重新选择；离线下载保留加密分段。云任务打开面板时读取，并每十秒更新。
- **个人菜单**：头像菜单集中提供账号与设备、网站风格、云服务、元数据与笔记备份、管理入口和退出登录。备份导出不包含书籍原文件。

保留居中小说排版、漫画阅读和阅读跳转历史。已验证网格/列表记忆、最近阅读切换与续读、批量标签/归档/回收站、导入失败后重新上传、下载与同步重试、部分失败重试、手机布局及深色风格。云服务继续任务使用模拟响应验证，未连接真实外部云账号；未部署线上网站。

## v1.14.0 阅读跳转历史

从目录、全文搜索、章节按钮或阅读进度跳到其他位置后，左下角出现“返回原位置”。点击返回后可使用“前进”再次查看目标位置。优先使用现有段落或图片锚点恢复，兼容章节与进度比例。

正常滚动、连续阅读自动接续、普通翻页和漫画翻页不累积历史。每本书本次打开最多保留 50 个跳转位置，关闭书籍后清空；返回后发起新跳转会清除旧的前进记录。此记录不跨设备同步，原有阅读进度同步不受影响。

## v1.12.0 加载诊断

打开书籍后可点击右下角“加载诊断”，首个失败会自动展开面板。

- 分别记录下载、解压、章节解析和图片加载的进行中、完成、失败及耗时；并行操作分开显示。章节解析可能包含下载和解压，日志不把网络在线等同于站点可访问。
- “重新打开书籍”取消旧下载并重试，沿用已保存的阅读位置；“重试当前页图片”复用图片重试功能。
- “复制诊断信息”复制版本、格式、文件大小、联网状态和阶段记录。浏览器拒绝剪贴板权限时，显示文本供手动复制。错误内容经过简化，不复制书名、正文、账号、下载地址或令牌。
- 最近记录仅保存在本页内存，面板展示最近 30 条；重新打开书籍或退出阅读会清理旧记录。面板关闭时不重绘列表。

![手机端加载诊断面板](docs/screenshots/loading-diagnostics.png)

尚未进入网站主界面时的站点加载故障无法由此面板诊断。后台预加载也会产生记录；对于格式库内部未暴露的步骤，显示在其所属解析阶段中，不推测具体原因。

## v1.11.0 正文清理、沉浸状态栏与电脑漫画

- **正文清理**：阅读设置中分别开启重复书名、广告、求票段落隐藏，也可填写自定义词句。先预览当前章节或分段，再应用；“恢复未清理正文”立即关闭清理。仅处理短文字段落，不修改原文件。预览最多展示前 6000 字和前 30 条匹配结果；规则可能误判，图片、代码和表格不作为清理目标。
- **沉浸状态栏**：时间、电量、章节进度分别开启，默认关闭。电量 API 不可用时显示“电量不可用”；阅读工具隐藏后状态栏仍保留。
- **电脑漫画**：宽度至少 1024 像素时，紧凑翻页区固定在阅读区域上方，整页图片适应可用高度，双页间距更清晰，减少重复章节按钮。保留双击放大、RTL、跨页识别及单个阅读滚动条。

已验证预览不改变正文、应用与恢复、状态栏开关、电脑双页和跨页翻页，以及移动横屏 RTL 回归。未在用户原书或实体手机上验证。

## v1.10.0 小说接续与排版

- **提前准备下一章**：连续阅读的文字章节显示后，在后台准备下一章；接近章末时复用已加载内容。预取失败不弹出打断提示，需要该章时沿用重试入口。并非一次下载整本书，速度仍取决于网络和章节大小。
- **接续位置稳定**：追加、回收或向上补回章节时，以仍在显示的章节节点为参照补偿位置变化。正文保留原节点，最多同时呈现五章，避免整页重建。
- **标题与后文衔接**：标题和短首段作为一个排版组合，双栏等分页场景尽量保持在一起；“下一页”按钮会为接近屏幕底部的标题预留后续两行空间。手动滚动仍自然移动，不强制吸附或跳转。
- **正文细节**：启用严格中文标点换行、长词换行及浏览器支持的自然断行；段间距沿用阅读设置。识别以引号开头的对话段落，避免多余首行缩进；尽量保留三行段首/段尾，具体效果取决于浏览器和排版模式。

不改动原书正文，不合并对话或删除空行。含图片章节不进行上述正文结构整理；代码块和表格也保留原结构。已验证预取后断网接续、当前节点与位置稳定、五章回收上限、横屏后向上接续及按钮翻页标题避让。尚未在用户原书或实体手机上验证。

## v1.9.0 漫画缩放与宽幅跨页

- **双指缩放与拖动**：在已经加载的漫画图片上双指缩放，进入临时查看层，最高放大至 5 倍；放大后单指拖动。双击或点击“适合屏幕”恢复完整显示，点击“关闭缩放”回到原阅读位置。桌面支持双击图片打开、滚轮缩放、鼠标拖动和 Esc 关闭。不修改原图或永久缩放设置。
- **宽幅跨页识别**：双页漫画模式默认检测实际图片比例，宽高比达到 1.2 的图片独占一组，前后的普通图片自动配对；支持从右向左和反向翻页。可在阅读设置中关闭“自动识别宽幅跨页”。这是按比例识别，并非识别画面中的书脊；宽幅插画也可能单独显示。
- **支持范围**：缩放查看适用于 EPUB/CBZ 等格式中已显示的图片（包括长条模式）；PDF 画布不进入图片缩放层。PDF 双页模式可根据页面比例单独显示横向页。检测只检查当前分组候选，不扫描整本图片。

已使用移动视口与浏览器真实触摸输入验证双指缩放、拖动、双击复位、关闭后保留页码；验证普通页—跨页—普通页前后切换、RTL、识别开关及横屏工具栏不遮图。尚未使用用户原始漫画或实体手机验证。

## v1.8.0 漫画工具与自动信息导入

- **漫画裁白边**：在“阅读设置 → 漫画图片”开启“自动裁白边”。识别接近纯白或透明的外边缘，保留少量边距；关闭开关即可恢复原图，不修改书籍文件。默认关闭。支持 EPUB/CBZ 中的图片和完整文件模式，PDF 画布暂不裁边。分析图最长 512 像素，裁后显示图最长 4096 像素；有纹理、泛黄或深色边框可能不会裁去。
- **图片位置记忆**：记录章节、具体图片序号及图内比例，重新打开自动恢复。云端接续也保存此位置；旧进度没有图片定位信息时仍使用原章节进度。与其他阅读记录一样，强制关闭页面可能丢失最后一小段未保存进度。
- **图片重试**：网络恢复后自动重试失败图片；联网状态下暂时失败会有限次延迟重试。可点击失败图片，或在阅读设置中点击“重试当前页图片”。原书缺少资源或图片损坏时仍需修复原书。
- **自动保存封面与简介**：书籍管理中选择“在线补全书籍信息 → 搜索并自动导入”，不再要求审批。采用 Open Library 首个匹配结果，自动保存书名、作者、年份、ISBN、简介并尝试可用封面。没有找到的字段保留原值；独立“搜索封面”也会直接保存首个可用结果。搜索仍由你主动发起，不会后台扫描整个书库。搜索匹配可能存在版本差异，保存后仍可手动编辑书籍信息或替换封面。

本地验证了裁边/恢复、图片位置重新打开与云端接续、断网恢复重试、当前页手动重试、信息及封面直接保存。云服务搜索测试使用本地模拟响应，未验证真实来源的收录率；未使用用户原始 EPUB 或实体手机测试。

## v1.7.0 大文件优化

- EPUB 先展示当前章节文字，图片进入附近可视区域后再加载，同时最多获取两张图片。
- 离开可视区域后释放漫画图片资源，保留尺寸以减少滚动跳动；加载失败可点击重试。
- 较大的 ZIP 压缩项交给 Web Worker 解压，减少手机主线程阻塞；合并部分范围请求，减少网络往返。
- 在线打开 4 MiB 及以上的支持格式优先分段读取，即使存在旧整本缓存或开启了自动整本下载。主动点击“立即下载整本并阅读”仍可下载全书。

本地模拟测试：Edge、390×844 视口、CPU 降速 4 倍、80 ms 延迟、2 MiB/s 下载速度。计时从点击书籍开始，至正文或第一张图片实际显示。

## 功能

- **继续阅读**：首页展示最近阅读的四本书，一键回到已保存位置。
- **智能目录**：TXT 自动识别章节并分批缓存目录，EPUB 读取原生导航，PDF 使用文档大纲；支持搜索和跳转。
- **连续滚动**：下一节直接接在当前正文之后，附近保留最多五节正文或五页 PDF。
- **离线下载管理**：下载进度、暂停、续传、筛选后批量下载和移除缓存。
- **阅读统计**：今日与累计阅读时长、阅读天数、已读书籍数和最近七天记录。
- **封面编辑**：上传 PNG/JPEG/WebP，或提取 EPUB/CBZ/DOCX 中可用的内置封面；书名、作者等仍可编辑。
- **网站风格**：青绿、暖纸、深色、极简四种风格，按账号保存，与阅读器配色独立。

- **多用户独立空间**：管理员创建用户、管理账号和容量配额；书籍与阅读记录按账号隔离。
- **多格式阅读**：TXT、EPUB、PDF、Markdown、HTML、DOCX、CBZ。
- **阅读记录同步**：同一站点账号同步进度、书签、笔记和阅读设置。
- **按需加载与离线缓存**：TXT、PDF、EPUB、CBZ、Markdown、HTML、DOCX 优先按格式按需读取，可在阅读设置中开启整本下载；本地阅读无需额外离线密码。
- **个性化排版**：12 种字体选项、10 套配色，以及自定义文字/背景颜色、字重、字间距等。未安装的字体会使用后备字体。
- **云端备份与恢复**：支持 OneDrive、Google Drive、WebDAV；百度网盘、阿里云盘通过 WebDAV 挂载服务接入。

> 云服务功能是应用格式的备份与合并恢复。它不是网盘文件浏览器，也不提供浏览器关闭后的常驻双向同步。

| D1 数据库 | 用户、书目、阅读记录等 | `cloud-reader-db` | `DB` |
| R2 存储桶 | 书籍原文件 | `cloud-reader-books` | `BOOKS` |

资源名称可以自定义，**绑定名称必须区分大小写，准确填写 `DB` 和 `BOOKS`**。R2 存储桶保持私有，无需开启公开访问，也不需要为本部署方式申请 R2 API 密钥。

部署包已经包含前端与后端，不需要运行 `npm install` 或构建命令。仅使用 GitHub Pages 无法运行此项目所需的后端。

## 方式一：控制台直接上传（适合首次部署）

### 1. 创建数据库和存储桶

在 Cloudflare 控制台中：

1. 找到 **D1**，创建数据库，例如 `cloud-reader-db`。
2. 找到 **R2 Object Storage**，创建存储桶，例如 `cloud-reader-books`。
3. 保持存储桶私有。

使用全新空数据库即可，程序首次访问初始化接口时会自动建表。**无需手动导入 SQL 文件。**

### 2. 创建 Pages 项目并上传

进入 **Workers & Pages → 创建应用 → Pages → 上传资产 / Direct Upload**，设置项目名称，上传发布包 ZIP 或解压后的部署文件夹。控制台文案可能随版本调整，请确认创建的是 Pages 项目。

部署根目录应直接包含：

```text
_worker.js
_routes.json
index.html
```

不能多套一层 `Cloud-Reader.v1.7.0/` 文件夹；不要上传整个开发工作区或 `node_modules`。

本项目采用 Pages Advanced Mode，后端入口为 `_worker.js`。Cloudflare 支持通过控制台直接上传这一形式的 Worker。参见 [Direct Upload 官方说明](https://developers.cloudflare.com/pages/get-started/direct-upload/) 和 [Advanced Mode 官方说明](https://developers.cloudflare.com/pages/functions/advanced-mode/)。

第一次部署后暂时看到配置提示是正常的，继续完成下面的绑定。

### 3. 添加 D1 和 R2 绑定

进入刚创建的 **Pages 项目 → Settings → Bindings → Add**，在生产环境添加：

| 绑定类型 | Variable name | 选择的资源 |
| --- | --- | --- |
| D1 database | `DB` | 第 1 步创建的数据库 |
| R2 bucket | `BOOKS` | 第 1 步创建的存储桶 |

`DB`、`BOOKS` 是资源绑定，不能用同名普通文本变量代替。绑定配置与重新部署要求可参见 [Pages Bindings 官方说明](https://developers.cloudflare.com/pages/functions/bindings/)。

### 4. 设置环境变量和密钥

进入 **Settings → Variables and Secrets**，为生产环境添加：

| 名称 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `ADMIN_USERNAME` | 文本变量 | 新站点必填 | 管理员用户名，3–32 位英文字母、数字、下划线或连字符 |
| `ADMIN_PASSWORD` | Secret | 新站点必填 | 管理员登录密码，8–256 位 |
| `DEPLOY_KEY` | Secret | 是 | 独立随机长字符串，作为服务端密钥长期保留 |
| `PASSWORD_PEPPER` | Secret | 否，建议首次部署时设置 | 独立随机长字符串，用于密码哈希；设置后应长期保留 |
| `SITE_QUOTA_GB` | 文本变量 | 否 | 站点应用容量上限，默认 `8`；可设置为正数 |

建议使用密码管理器分别生成至少 32 位随机字符串。不要将实际密钥提交到 GitHub。`DEPLOY_KEY` 由你自己设置，不是 Cloudflare API Token，也不是管理员登录密码。

**账号创建后不要随意更改这两个密钥。** 未显式设置 `PASSWORD_PEPPER` 时，程序会从 `DEPLOY_KEY` 派生密码 pepper；此时修改 `DEPLOY_KEY` 或补填不同的 `PASSWORD_PEPPER` 都会影响已有账号的密码验证。

`SITE_QUOTA_GB` 是程序限制，不代表 Cloudflare 套餐赠送的容量，也不会替你调整平台计费或配额。

### 5. 重新部署

保存绑定和变量后，回到项目部署页面，再次上传同一份部署包，创建新部署，使配置生效。

等待部署成功，打开 Cloudflare 分配的 HTTPS 地址：

```text
https://你的项目名.pages.dev/
```

### 6. 登录管理员

保存 `ADMIN_USERNAME` 和 `ADMIN_PASSWORD` 并重新部署后，打开网站。程序会自动创建管理员，无需在网页输入初始化密钥。使用这两个变量中的账号密码直接登录，然后导入一本 TXT 或 EPUB 检查阅读功能。

如需改名或重置管理员密码，在 Pages 修改对应变量并重新部署；下一次访问登录状态接口或登录时会应用配置，旧管理员会话随凭据变更失效。管理员用户 ID、书籍和阅读记录不变。如果用户名已被其他用户使用，会提示配置冲突，不会将该用户提升为管理员。

升级旧站点时配置这两个变量，会接管原始管理员账号；不配置则保留旧账号登录方式。新站点必须同时配置两项，网页初始化接口已关闭。

### 7. 创建其他用户

管理员登录后进入 **用户与独立空间 / 用户管理**，创建账号并设置配额。用户使用各自账号登录，每个账号拥有独立的书库和阅读记录。

不要让不同使用者共用同一个账号，否则他们会共享该账号的空间。

## 可选：配置外部云服务

基础阅读功能不依赖外部网盘，可以先完成站点部署，再按需配置。

入口：**设置与数据 → 云服务**，或直接访问 `/cloud`。

| 服务 | Pages 项目中需配置 | 接入说明 |
| --- | --- | --- |
| OneDrive | `ONEDRIVE_CLIENT_ID`、`ONEDRIVE_CLIENT_SECRET` | 注册 Microsoft OAuth 应用后授权 |
| Google Drive | `GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET` | 启用 Drive API，创建 Web OAuth 客户端 |
| WebDAV / Nextcloud / ownCloud | `WEBDAV_ALLOWED_HOSTS` | 在网页填写 HTTPS WebDAV 地址与凭据 |
| 百度网盘 / 阿里云盘 | `WEBDAV_ALLOWED_HOSTS` | 先准备挂载对应网盘的可写 WebDAV 服务 |

OAuth 客户端密钥应保存为 Secret，配置更改后重新部署。回调地址必须与实际站点域名完全一致：

```text
https://你的域名/cloud/oauth/onedrive/callback
https://你的域名/cloud/oauth/google/callback
```

OneDrive 使用 `Files.ReadWrite.AppFolder` 权限及离线授权；Google Drive 使用 `https://www.googleapis.com/auth/drive.appdata` 范围。Google 应用处于测试状态时，需要将使用者加入测试用户列表。

WebDAV 配置示例：

```text
WEBDAV_ALLOWED_HOSTS=dav.example.com,cloud.example.com
```

这里只填写允许访问的域名，不填协议、路径或通配符。网页中的目录地址则填写完整 URL，例如 `https://dav.example.com/CloudReader/`；预先创建此目录。当前支持标准 HTTPS 443 端口，请使用最终地址，服务不能依赖重定向。

百度网盘、阿里云盘当前没有原生 OAuth/API 适配器。页面需要的是 WebDAV 用户名和应用密码，不是网盘登录密码。

云备份包含书籍、书目和阅读记录；合并恢复导入缺失书籍并合并较新记录。备份绑定同一站点的用户 ID，不提供跨站点账号映射。自动备份仅在云服务页面打开且联网时每 15 分钟运行。

外部云服务已做模拟协议测试，仍需部署者使用自己的真实账号完成联调。

1. 备份重要数据，并记录现有资源绑定和密钥配置。
2. 将新版部署文件上传到**现有 Pages 项目**，或更新 Git 集成项目的部署目录。

## 常见问题

### 页面提示“Pages 后端尚未运行”

检查部署根目录是否直接包含 `_worker.js`，是否误传了外层文件夹，以及是否创建了 Pages 项目。单独双击 `index.html` 或部署到 GitHub Pages 无法运行后端。

### 页面提示缺少 DB、BOOKS 或 DEPLOY_KEY

检查绑定名称、资源类型和生产环境变量是否正确，确认保存后已经重新部署。生产环境与预览环境的配置分别生效。

### 数据库初始化失败

确认 `DB` 绑定到可用的 D1 数据库。新部署使用空数据库即可；旧站点保留原数据库。查看 Cloudflare 部署及运行日志，不要通过清空数据库解决问题。

### 管理员账号或密码未配置

在 Pages 的生产环境设置 `ADMIN_USERNAME` 和 Secret `ADMIN_PASSWORD`，保存并重新部署。密码按原值使用，不会删除前后空格。`DEPLOY_KEY` 仍须保留，但不再是网页初始化凭据。

### TXT 打开白屏

确认部署的是 v1.7.0 或包含同一缓存修复的后续版本，然后刷新页面。v1.7.0 统一了整套静态资源的缓存地址，修复了旧模块混用导致的白屏。如果仍失败，请记录书籍格式、大小及浏览器报错以便排查。

### 为什么有些书仍然需要读取较多数据？

PDF 的索引、字体和页面资源可能分散在文件各处；DOCX 的正文通常集中在一个压缩 XML 项中，必须先读取该项。小文件也可能在首个范围内全部读完。按需读取减少不必要传输，不保证每种文件都能只取第一页的字节。

### 离线时无法打开某本书

先联网登录并完整缓存该书。分段阅读过部分正文不代表整本书已经可离线使用。浏览器清理站点数据会影响本地缓存。

### 修改密钥后原密码无法登录

密码验证依赖创建账号时使用的 pepper。优先恢复原有密钥配置；不要删除数据库或重新初始化站点。

### 云服务无法连接

检查客户端 ID、Secret、OAuth 回调地址、测试用户列表，或 WebDAV 域名白名单、目录权限与最终 URL。修改 Pages 配置后重新部署。

## 数据存储与容量

账号和阅读元数据保存在 D1，书籍文件保存在私有 R2，本地缓存按账号保存在浏览器。站点配额默认 8 GB，单本上传上限 200 MB；实际可用容量和请求额度还受到 Cloudflare 平台限制。

管理员应同时备份 D1 和 R2：只有数据库或只有书籍文件，都不足以完整恢复站点。云备份不替代站点数据库备份。不要把真实密钥、个人书库或用户数据提交到公开仓库。

## 渐进阅读方式

| 格式 | 打开与后续加载方式 |
| --- | --- |
| TXT | 读取当前字节分段，并预加载下一段 |
| PDF | 通过 16 KB 范围请求读取必要索引、页面和字体，关闭自动整本获取，并预取下一页资源 |
| EPUB | 先读取 ZIP 目录和书籍索引，再取当前章节；图片按可视区域加载，预加载下一章 |
| CBZ | 先读取 ZIP 目录，再取当前图片页，预加载下一页 |
| DOCX | 先读取正文 XML 和必要元数据，按节转换，图片按当前节读取 |
| Markdown / HTML | 连续按范围读取，在段落或块边界分节，预加载下一节 |

翻页或下拉遇到尚未就绪的内容时保留当前正文，准备好后再切换。后台预取失败不会打断当前阅读；需要该节时可重试。退出阅读会取消相关请求。离线时使用完整本机缓存；在线打开大文件优先范围读取，避免整本读取和解密阻塞首屏。

阅读设置保留“打开时下载完整书籍”和“立即下载整本并阅读”。为优先显示首屏，在线打开 4 MiB 及以上的支持格式时忽略自动整本下载偏好；需要全书请主动下载或使用离线下载管理。分段浏览不等同于整本离线缓存。

注意：

- DOCX 无法在通用 ZIP 压缩正文项的任意位置直接解码，正文 XML 仍须先读取；图片附件不会因此全部下载。
- PDF 实际读取量取决于索引布局；某些 PDF 需要读取很多范围，甚至完整文件。
- 单个 ZIP 项解压后超过 32 MiB 时，渐进路径会拒绝加载；单章超长 HTML 的解析也可能耗时。旧离线整本缓存仍有完整读取与解密成本。
- ZIP64、分卷、加密书籍，以及过大的单个压缩项不走当前渐进路径；可尝试完整下载模式，原解析器也未必支持加密书籍。
- Markdown 的跨段引用、复杂 HTML 外层布局，以及 DOCX 跨节排版可能需要完整下载模式保留最佳效果。
- Markdown / HTML 的目录随读取展开，恢复后面的位置时需要先定位前面的分节边界。
- FB2 等未列入上表的格式沿用原解析方式。

本地验证使用 Edge：桌面 1440×960、移动视口 390×844。已检查多格式打开及翻页、206 范围请求、慢网保留正文、请求失败后重试、TXT 下拉、资源版本一致性和账号隔离；未在用户线上站点或真实私人书库中测试。

## 已有功能使用方法

### 继续阅读与网站风格

首页顶部显示“继续阅读”，最多展示四本最近阅读的书。网站风格选择器位于此区域右侧，设置会随账号同步。首次打开时优先使用本机已同步的阅读位置；云端同步在后台进行，不在开始阅读后突然移动位置。

### 智能目录

阅读器中打开“目录”，可搜索标题并跳转。TXT 在目录面板打开时由后端每批扫描 256 KB，结果保存在 D1，关闭面板会停止继续请求；下次从上次扫描位置继续。最多识别 8000 项，达到上限会提示。EPUB 优先读取 EPUB 3 导航或 EPUB 2 NCX；缺少导航时使用章节列表。PDF 优先使用文档大纲，缺少大纲时使用页码。

目录按需生成，不会在每次打开书籍前扫描完整文件。TXT 依赖常见“第某章”“Chapter 1”等标题规则，特殊写法可能需要使用分段列表定位。

### 连续滚动

在“阅读设置 → 翻页模式”选择“连续滚动 · 自动接续章节”。没有旧设置的新书默认使用连续滚动，已有排版设置保持原样。原有上下滚动、简约和仿真翻页模式仍保留。

连续模式按需追加下一节，并回收远离当前位置的正文节点；向上阅读时可重新载入前面的内容。网络失败会显示重试入口。PDF 连续模式保留可选择文本层。

### 离线下载管理

在首页打开“离线下载管理”，搜索书名并下载，或使用“下载筛选结果”加入队列。队列一次处理一本书，每段 1 MB；暂停或刷新后可继续已保存的分段。完成后校验 SHA-256，校验通过才标记为已缓存。

下载需要浏览器页面保持打开，关闭浏览器不会继续下载；刷新后需手动点“继续”。任务和分段保存在当前账号的本机缓存中，不会在另一台设备自动出现。可移除任务或缓存释放空间。完整文件合并和校验需要一定内存，较大的书仍受设备与浏览器存储限制。

### 阅读统计

统计从本版本开始，不会虚构以前的阅读时长。仅在页面可见、最近两分钟内有阅读操作时累计，每十秒保存，并在离开阅读器时尝试补存。强制关闭浏览器可能损失最后一小段尚未保存的时间。记录随账号同步，多个会话分别记录。

### 书籍信息与封面

在书籍的“管理”按钮中修改书名、作者、标签、状态和评分。封面可上传 PNG/JPEG/WebP（原图不超过 12 MB），程序会压缩为最长 240×340 的缩略图后保存，不会把原始大图放进书架。

“提取内置封面”支持 EPUB 声明的封面图片、CBZ 第一张图片和 DOCX 中存在的缩略图。文件没有内置封面时可以手动上传。点击“恢复默认封面”移除自定义封面。封面随账号同步。

### 性能与验证

- 打开书籍不再等待整轮同步完成，阅读器模块与正文准备并行。
- 连续模式限制同时渲染的章节或 PDF 页数，目录只在需要时构建。
- 下载队列单任务执行，封面使用缩略图，同步批次按字节数限制。
- 本地 Edge 在桌面 1440×960、手机 390×844 验证了目录、封面、连续阅读、下载暂停/刷新后续传、断网打开缓存、统计、四种风格及账号隔离。
- 在本地人为给同步接口增加 2 秒延迟的对照测试中，TXT 首屏由约 2.59 秒降至约 0.47 秒。这个结果只代表该测试条件，不是对所有网络和书籍的速度承诺。

升级无新增环境变量，沿用原 DB、BOOKS 和管理员配置。TXT 目录缓存表在首次使用时自动创建，不需要手动执行 SQL。
